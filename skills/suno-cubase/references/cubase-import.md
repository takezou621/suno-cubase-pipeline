# Cubase への AAF 取り込み手順

生成された `<曲名>.aaf` は音声を埋め込んでいる単一ファイルです。
Cubase の AAF 読み込みに対応する版（Pro / Artist。実機検証は Cubase 16 Pro）で
次の手順で取り込みます。

## 手順

1. **新規プロジェクトを作成**
   - サンプルレートは AAF と同じ値（`analysis.json` の `sample_rate`、通常 44.1 kHz または 48 kHz）にする。
   - 新規作成時にサンプルレートを選べない環境では、既定のまま読み込んでから
     「プロジェクト > プロジェクト設定」で合わせる。
2. **AAF を読み込む**
   - メニュー「ファイル > 読み込み > AAF…」で `<曲名>.aaf` を選択。
   - メディアのコピーを尋ねられたら「コピー」を選ぶ（プロジェクトの Audio フォルダに取り込まれる）。
3. **確認**
   - ステムごとのトラック（vocals / drums / bass / guitar / piano / other）が並ぶ。
   - すべてのクリップが小節 1（プロジェクト先頭）から始まっている。
   - ミックスダウンして元音源と A/B 比較し、分離漏れがないか確認する。
4. **保存**
   - 「ファイル > 保存」で `.cpr` として保存。以降は通常の Cubase プロジェクトとして
     編集（クオンタイズ、打ち込み、ミックス）できる。

## Cubase 15/16 での読み込みステータス (2026-11-10 検証)

- **v0.1.0 (pyaaf2 既定構造)**: 埋め込み/リンク essence、PCM_16/24、44.1/48k の
  全組み合わせで `AAFfilter` が SIGSEGV クラッシュ
  （[pyaaf2 issue #103](https://github.com/markreidvfx/pyaaf2/issues/103) と同根）。
- **v0.2.0 (DaVinci Resolve 準拠構造)**: Timecode slot / PhysicalTrackNumber /
  WAVEDescriptor (Summary=RIFF fmt) / WAV形式埋め込み essence / OperationalPattern 削除。
  **Cubase 16 Pro 16.0.5 と Cubase 15 の両方でクラッシュせず、6 トラックが
  正しい名前・順序で生成されることを確認**。
- **残存課題**: Cubase 16.0.5 のインポーターは埋め込みメディアの解決に不具合があり、
  クリップが未配置のまま終わる（「unresolved media reference」警告）。
  **DaVinci Resolve 書き出しの AAF でも同一の結果**のため Steinberg 側の問題
  （バージョンアップでの改善を注視）。
- **メディア実体を確実に入れる方法**: 空プロジェクトにステムWAVを
  「ファイル > 読み込み > オーディオファイル…」で直接読み込んで .cpr 保存する
  （実証済み。6 トラック構成は同様に得られる）。

### GUI 自動化する場合

- メニュー操作は AX (`menu_press`) で確実に実行できる
- 読み込みパネルのファイル行は AX で `AXTextField` として露出するので、
  行の `AXPosition` から座標クリックし、「開く」ボタンは `AXPress` で押せる
- パネルの検索フィールドは `AXValue` 直接設定 + `AXConfirm` で目的フォルダを絞り込める
- 保存ダイアログのファイル名フィールドは `AXValue` 直接設定で書ける
- キーボードイベント（Cmd+Shift+G 等）と修飾キー付きクリックは
  Cubase のパネルに届かないことがあるため、マウス単体の操作で完結させる

## よくある質問

| 状況 | 対処 |
|---|---|
| トラック名が期望と違う | AAF 側のスロット名がそのまま使われる。Cubase でリネームするか、ステムWAVのファイル名を変えて `build-aaf` を再実行 |
| 音が 44.1k と 48k で混在する | 本ツールは単一サンプルレートのみ出力する。プロジェクト設定を AAF に合わせる |
| 読み込みに時間がかかる | 埋め込み音声のコピー（3〜4 分曲で数百 MB）が発生するため。初回のみ |
| 商用利用 | Suno のプラン規約と、配布モデル（Demucs: MIT）の条件を確認 |

## 自動化（任意）

Cubase を MIDI Remote API / macOS Accessibility 経由で操作する MCP ブリッジ
（例: `cubase-midi-remote-api` の `gui_menu_press`）が導入済みなら、
「新規プロジェクト → AAF 読み込み → 保存」までを自動実行できる。
メニュー名の実行時の表記（日本語 UI では「ファイル > 読み込み > AAF…」）は
環境ごとに確認すること。
